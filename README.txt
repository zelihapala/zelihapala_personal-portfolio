
# My Personal Portfolio Website

This is my personal portfolio website, where I share my education, technical skills, projects and certificates.

I created this website to bring my IT learning and practical work together in one place. My main areas of interest are IT Support, Networking and Cybersecurity.

## Website Features

- Personal introduction and About Me section
- Technical skills
- IT and networking projects
- Certificates and badges
- GitHub and LinkedIn links
- Contact section
- Responsive design for laptops, tablets and mobile phones

## Technologies Used

- HTML5 – Website structure and content
- CSS3 – Layout, colours and responsive design
- JavaScript – Mobile navigation and automatic footer year

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
